# Picard-Based Acceleration of Newton Continuation for Mean Field Game PDE Systems

Numerical experiments for the manuscript by **Mathieu Laurière and Andrew Shi (2026)**. The paper develops and illustrates a hybrid strategy that uses inexpensive Picard iterations before handing the solution to Newton continuation. Studying the component solvers identifies when combining them is useful and when one method should be favored.

Contact: [andrewshi@math.berkeley.edu](mailto:andrewshi@math.berkeley.edu)

## Organization of the experiments

The examples follow the current manuscript's order:

| Paper section | Benchmark | Purpose |
|---|---|---|
| 4.1 | [Discounted MFG](https://github.com/andrewjshi/2026-pap-Newton/tree/main/DISCOUNTED%20%281D%29) | Validate both solvers against a known stationary solution. |
| 4.2 | [Ergodic MFG](https://github.com/andrewjshi/2026-pap-Newton/tree/main/ERGODIC%20%281D%29) | Validate the stationary structure and study the vanishing-discount limit. |
| 4.3 | [Nonlocal congestion](https://github.com/andrewjshi/2026-pap-Newton/tree/main/CONGESTION-NONLOCAL%20%281D2D%29) | Illustrate a regime favoring Picard because of dense spatial coupling in the assembled Newton Jacobian. |
| 4.4 | [Traffic light](https://github.com/andrewjshi/2026-pap-Newton/tree/main/TRAFFIC-LIGHT%20%281D%29) | Examine damping sensitivity and Newton continuation in the presence of a temporal shock. |
| 4.5 | [Double-well potential](https://github.com/andrewjshi/2026-pap-Newton/tree/main/DOUBLEWELL%20%281D2D%29) | Study Picard's viscosity limits and demonstrate Picard-based acceleration of Newton continuation in 2D. |

**Picard** alternates a backward HJB solve, using spatial Newton steps, with a forward FP solve. **Newton** solves the coupled space-time nonlinear system. The reported comparisons use direct sparse linear solves (`spsolve`/SuperLU).

The **hybrid method** is presented in three phases:

1. Picard descent through decreasing viscosities, retaining the damping parameter across levels. Every attempt starts independently from zero value and a density history generated by pure diffusion.
2. Picard failure at the next lower viscosity after exhausting the damping schedule, identifying the last successful viscosity for the handoff.
3. Newton re-solve from the last successful Picard solution, followed by Newton continuation to the target viscosity.

Both timing histories use **direct sparse solves**, `N_h = 200`, `N_T = 100`, and `T = 1`:

| Method | Viscosity | Damping / continuation | Stopping criterion | Recorded solver time |
|---|---|---|---|---:|
| Newton | Target `ν = 0.001` | `0.2 → 0.01 → 0.001`, `TAU = 0.05` | Coupled residual below `1e-9` | **7.5534 s** |
| Picard | `ν = 0.02` | `θ = 0.1` | Relative changes below `1e-6` | **25.7415 s** |

These histories support the speed statement in Section 4.4: Newton's recorded solver time was about **29% of Picard's (a 3.4-fold speedup)**, and Newton reached a **twenty-fold smaller viscosity**. Newton's time includes all continuation solves and excludes visualization. Its new timing run used one thread for the numerical libraries; the Picard timing is taken from the existing log without a fresh rerun. The target viscosities and stopping criteria differ as shown above. The Picard run converged in 141 iterations; the Newton run ended with a coupled residual of approximately `1.72e-12`.

Tables 4–6 use `N_T = 10` and the viscosity schedule `1, 0.3, 0.1, 0.03, 0.01, 0.003, 0.001, 0.0003, 0.0001`.

- **Table 4** records each Picard viscosity run separately, including damping retries. Each attempt starts independently. Lower-viscosity rows marked `failed_by_monotonicity` in the CSV were skipped after the first unsuccessful viscosity.
- **Table 5** records cumulative Newton continuation times, starting independently at `ν = 1` for each grid and reusing converged solutions within that row.
- **Table 6** uses `N_h = 128`: Picard succeeds through `ν = 0.01`, fails at `0.003`, and hands Newton the solution at `0.01`. The hybrid reaches `ν = 1e-4` in **19,563.5 s**, compared with **46,410.5 s** for the corresponding Newton-only continuation.

The hybrid CSV labels the Newton re-solve and subsequent continuation as code phases 3 and 4; the manuscript groups them together as Phase 3. Raw Newton iteration counters include the final convergence check, while the manuscript reports Newton updates.
